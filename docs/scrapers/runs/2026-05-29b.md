## Ändringar

### Tickster H1: Beskrivningar

**Problem:** Tickster-scraper sparade 0% beskrivningar. JSON-LD på Tickster-sidor saknar `description`.

**Fix:**
- Lagt till DOM-extraktion: `<p>` utan klass vars förälder också saknar klass → är beskrivningsstycken.
- Filter bort datumraden (`u-font--mono`-klass) och footer-adresser (`o-grid`-förälder).
- Cookie wall (CybotCookiebot) bypassas via `page.setCookie` med förkonsent.

**Verifikat:** "Metta Breathwork" → 2972 chars, "The Love That Remains" → 836 chars.

### Tickster H2: Garbage-titlar

**Problem:** 8 events med titel "Tickster Event" (sök-sidor råkade sparas).

**Fix:** Titel-guard — hoppar om `title === 'Tickster Event'`.

### Tickster H3: Bättre kategori-classifier

**Problem:** `guessCategoryFromTitle` gav "Shrek the musical" → `food` (mat/musical-bug), Sinfonietta → other.

**Ändringar:**
- `comedy` separerat från `culture`
- `performing-arts` med `musical/revy/dansshow`
- `music`: `konsert` som substring (fångar releasekonsert), `sinfoni`, `gitarr`
- `food-drink`: word boundary för `mat` — fixar musical-buggen
- Nya regler: `outdoor`, `family` (sagotr-prefix), `training`, `art`, `education`

**Backfill:** 12 befintliga Tickster-events reklassificerade.

### Meetup: Beskrivningar

**Problem:** `extractMeetupEvent` returnerade inte `description` trots att JSON-LD har den.

**Fix:** Lade till `description: d.description ? String(d.description).trim() : ''` i return-objektet och i `addEventToDb`-anropet.

**Verifikat:** "Stockholm Culture Exchange" → 155+ chars från JSON-LD.

### Meetup: Kategori-classifier

Uppdaterad till samma kvalitet som Tickster — `comedy`, `performing-arts`, `training`, `game`, `social`, `outdoor`.

### K4-gräns: 200 → 500

`LIMIT 200` → `LIMIT 500` i `llm-enrich-missing.ts`.
Träffar nu fler av de 256 lat=0-events (var 300+ men sjönk tack vare K2+K4).

### Dansk titel-filter

**Problem:** "Bygglek lørdag", "Åbent lørdag" klarade `isForeignAddress` (som bara kollar adressfältet).

**Fix:** Lagt till titel-check direkt i FB-scrapers pre-save-logik:
```typescript
const DANISH_TITLE_WORDS = /\b(lørdag|søndag|mandag|tirsdag|onsdag|torsdag|fredag|åbent|åbner|lukket|hvad\s+sker)\b/i;
if (DANISH_TITLE_WORDS.test(details.title)) { continue; }
```

### classify.ts: Nya regler (FB)

Lade till `training`, `game`, `party`, `outdoor` som egna kategorier.
Separerade `sport` (match, turnering) från `training` (yoga, löpning, fitness).
Lade till `musical`, `revy` i `performing-arts`.
