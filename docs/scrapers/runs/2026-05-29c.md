## Ändringar

### Eventbrite: Puppeteer-scraper (komplettrewrite)

**Problem:** Gamla eventbrite.ts använde `fetch` + cheerio — fick 0 events eftersom sidan är React-renderad.

**Ny strategi:**
1. Puppeteer laddar `https://www.eventbrite.se/d/sweden--{city}/events/`
2. Extraherar `section[class*="discover-vertical-event-card"]` — en per unikt event
3. `h3` (ej h2!) → titel, `p[0..n]` → datum+lokal (smart badge-detektering)
4. Tolkar svenska datumformat: "idag kl. HH:MM", "imorgon", "DD MONTH HH:MM", "WEEKDAY kl. HH:MM"
5. Geocodar lokal + stad via Nominatim
6. Sparar events inom 30 dagar (längre window än andra scrapers — biljettevents bokas i förväg)

**Städer:** Stockholm, Göteborg, Malmö, Uppsala, Linköping, Örebro, Helsingborg, Norrköping, Jönköping, Umeå, Västerås, Sundsvall, Lund, Karlstad (14 st)

**Verifikat (test mot tmp-DB):** 69 events sparade, 69/69 geocodade. Exempel:
- Pub Crawl in Stockolm @ City Backpackers Hostel Stockholm ✅
- KRS One Live in Stockholm @ Fryshuset Klubben ✅
- PEAK PERFORMANCE HIKE CLUB STOCKHOLM ✅

**Kvarstående:** Några tyska online-events (anm. till Stockholm) läcker igenom — har inga svenska koordinater men geocodas till städers centrum. Acceptabelt för nu.

### Eventim SE: Ny scraper

**Strategi:**
- Puppeteer laddar kategorisidor (Musik, Humor, Kultur, Musikal, Familj)
- Extraherar JSON-LD `itemListElement` — innehåller name, startDate, location, offers.url
- Individuella event-sidor och artist-sidor blockeras av Akamai WAF — ej nödvändigt
- Kategori-URL används som fallback-kategori om classifyEvent returnerar 'other'

**Kategorier som scrapes:**
- Konserter(47), Rock(19), Humor(21), Pop(1), Hip-Hop/Rap(4), Indie(1), Musikaler(1), Festivaler(7), Utställning(4), Föredrag/Kurs(5), Talkshow(2), Rundvisning(1), Familj/Barn(4)

**Verifikat (test mot tmp-DB):** 8 events sparade (inom 30d), 8/8 geocodade. Exempel:
- ÄLSKADE VÄN! - FILIP & FREDRIK LIVE @ Draken Live, Göteborg ✅
- Jimmy Carr - Laughs Funny @ Sparbanken Skåne Arena, Lund ✅
- KRS One LIVE IN GOTHENBURG @ Nefertiti ✅

## Tekniska detaljer

**Eventbrite datumparser fixar:**
- `p[0]` kan vara badge ("Sales end soon", "Going fast") — `findDateAndVenue()` hoppar dessa
- `h3` (inte `h2`) för titel — ändrades under investigation
- "torsdag kl. 08:30" → nästa torsdag (utan datumnummer)
- "CEST" strippas ur datumsträng
- 30-dagars window (mot 7d för community-scrapers)

**Eventim kategori-hints:**
- Används som fallback när `classifyEvent(title)` returnerar 'other'
- "Extreme" (bandet) → 'music' (från konserter-kategori) ✅
- "Simon Brodkin" → 'comedy' (från humor-kategori) ✅
